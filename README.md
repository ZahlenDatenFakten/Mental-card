# Mental Card (Ментальная Карта) — Logic Tree Canvas

> Современное, быстрое и утилитарное веб-приложение для построения ментальных карт (Mind Maps) с горизонтальным древовидным холстом (Logic Tree), строгим темным дизайном в стиле Linear / Raycast / Obsidian и полным управлением с клавиатуры.

---

## ⚡ Особенности и возможности

### 1. Древовидный холст (Logic Tree)
- **Двухпроходный математический алгоритм**: расчет координат узлов (Left-to-Right) без пересечений с выравниванием по вертикали относительно диапазона дочерних элементов.
- **Кубические сплайны Безье**: плавные векторные соединительные линии с динамическими точками привязки и подсветкой активной ветки.
- **Сворачивание / Разворачивание ветвей**: интерактивные кнопки с бейджем количества скрытых узлов.
- **Интерактивная миникарта**: масштабируемое превью всей структуры карты в правом нижнем углу с индикатором области видимости и быстрой навигацией по клику.
- **Бесконечный Canvas**: панорамирование (Drag, Space+Drag, колесо мыши) и плавный зум в точку курсора.

### 2. Управление «Клавиатура в первую очередь» (Keyboard-First UX)
- <kbd>Tab</kbd> — добавить дочерний узел и перейти в режим редактирования.
- <kbd>Enter</kbd> — добавить соседний узел (sibling) на том же уровне.
- <kbd>F2</kbd> / Двойной клик — редактирование текста по месту (inline edit).
- <kbd>Backspace</kbd> / <kbd>Delete</kbd> — удалить узел со всем поддеревом.
- <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> — мгновенная навигация по иерархии дерева.
- <kbd>[</kbd> / <kbd>]</kbd> — свернуть / развернуть ветку.
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Z</kbd> и <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> — отмена и повтор действий (Undo/Redo до 50 шагов).
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>F</kbd> — быстрый поиск узлов с хлебными крошками и мгновенным прыжком.
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>B</kbd> — боковой инспектор свойств.
- <kbd>?</kbd> / <kbd>F1</kbd> — справочник горячих клавиш.

### 3. Экспорт, импорт и метаданные
- **Экспорт в PNG**: растровое изображение высокого разрешения (Hi-DPI 2x Retina).
- **Экспорт в SVG**: чистый векторный файл без потери четкости.
- **Экспорт и импорт в JSON**: резервная копия полной структуры карты со всеми параметрами.
- **Импорт Markdown**: автоматическое построение древовидной структуры из списков с отступами или табуляцией.
- **Боковой инспектор**: Markdown-заметки, внешние ссылки на источники, палитра цветов ветвей, приоритеты (!high, !medium, !low) и `#теги`.
- **Автосохранение**: синхронизация изменений в `localStorage`.

## 🛠 Стек технологий

- **Фреймворк**: React 18 / TypeScript
- **Сборщик**: Vite
- **Стилизация**: Tailwind CSS (палитра Zinc/Slate) + Plus Jakarta Sans / Inter / JetBrains Mono
- **Иконки**: Lucide Icons (SVG)
- **Управление состоянием**: Zustand с кастомным стеком истории действий

## 🚀 Установка и запуск

### Требования
- Node.js >= 18.0.0
- npm >= 9.0.0

### Запуск проекта локально
```bash
# Клонирование репозитория
git clone https://github.com/ZahlenDatenFakten/Mental-card.git
cd Mental-card

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

### Сборка для продакшена
```bash
npm run build
npm run preview
```
