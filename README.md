# Юридическая ментальная карта (Legal Mind Map & Litigation Workspace)

> Специализированное аналитическое веб-приложение для юристов, адвокатов и судебных представителей: построение логических цепочек доказательств, правовой позиции, хронологии фабулы дела и оценка рисков в судебных процессах.

---

## 🏛️ Ключевые возможности

### 1. Юридическая категоризация блоков (Legal Entity Tree)
- ⚖️ **Тезис / Позиция стороны**: ключевое утверждение с привязкой норм права и доказательств.
- 📅 **Факт / Хронология**: событие фабулы дела с фиксацией даты, времени и примечаний.
- 📜 **Норма права**: статьи законов (ГК, АПК, ГПК, УК, ТК РФ), правовые позиции Пленумов ВС РФ и судебные прецеденты.
- 📁 **Доказательство**: письменные документы, экспертизы, свидетельские показания с указанием тома и листов дела (`т. 1, л.д. 28-32`), статуса приобщения и силы доказательства (1-5 звезд).
- 🛡️ **Довод оппонента**: аргументы противной стороны и прогнозируемые возражения.
- ⚡ **Опровержение**: контр-аргументы и контр-доказательства.
- ⚠️ **Риск / Уязвимость**: слабые места позиции в процессе.
- 🎯 **Исковое требование**: просительная часть иска.

### 2. Интерактивная хронология (Timeline View)
- Автоматическое извлечение всех датированных событий и фактов дела.
- Хронологическая таблица с ссылками на листы дела и быстрым прыжком к блоку на холсте.
- Экспорт хронологии в **CSV** и **Markdown**.

### 3. Автоматический генератор судебного меморандума (Court Position Document)
- Формирование полного структурированного процессуального документа в один клик:
  1. *Фабула дела и хронология событий*.
  2. *Правовое обоснование и тезисы*.
  3. *Нормативная база и цитаты судебных актов*.
  4. *Реестр доказательств (с томами и л.д.)*.
  5. *Оценка рисков и возражений оппонента*.
  6. *Просительная часть иска*.
- Поддержка печати в **PDF** и копирования в буфер обмена.

### 4. Мгновенный шеринг дела (Sharing via URL)
- Вся карта и материалы дела упаковываются в URL-ссылку с помощью LZ-String сжатия.
- Передача дела коллегам, доверителям и экспертам в один клик без необходимости регистрации.

### 5. Библиотека готовых судебных шаблонов
- **Арбитраж**: Взыскание задолженности и неустойки по договору поставки.
- **Корпоративные споры**: Оспаривание решения общего собрания участников (ВОСУ) ООО.
- **Трудовые споры**: Признание увольнения незаконным, восстановление и взыскание среднего заработка.
- **Чистый кейс**: Построение своего судебного процесса с нуля.

### 6. Управление «Клавиатура в первую очередь» (Keyboard-First UX)
- <kbd>Tab</kbd> — добавить дочерний блок.
- <kbd>Enter</kbd> — добавить соседний блок на том же уровне.
- <kbd>F2</kbd> / Двойной клик — редактирование текста по месту.
- <kbd>Backspace</kbd> / <kbd>Delete</kbd> — удалить блок со всем поддеревом.
- <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> — мгновенная навигация по дереву.
- <kbd>[</kbd> / <kbd>]</kbd> — свернуть / развернуть ветку.
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Z</kbd> и <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> — отмена и повтор действий (Undo/Redo до 50 шагов).
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>F</kbd> — поиск по статьям, датам, доказательствам и тезисам.
- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>B</kbd> — боковой инспектор доказательств и законов.

## 🛠 Стек технологий

- **Фреймворк**: React 18 / TypeScript
- **Стилизация**: Tailwind CSS (Zinc/Slate) + Plus Jakarta Sans / Inter / JetBrains Mono
- **Иконки**: Lucide Icons (SVG)
- **Управление состоянием**: Zustand с историей Undo/Redo и localStorage
- **Сжатие URL**: LZ-String

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ZahlenDatenFakten/Mental-card.git
cd Mental-card

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Продакшен-сборка
npm run build
```
